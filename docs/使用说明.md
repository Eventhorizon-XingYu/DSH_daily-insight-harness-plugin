# Daily Insight DSH 插件使用说明

## 1. 这个插件有什么用

Daily Insight 是一个接入 DeepSeek Harness（简称 DSH）的每日资讯插件。它把下面几步连接起来：

1. 根据配置的主题搜索网页资讯。
2. 对搜索结果去重并保留真实来源链接。
3. 搜索 YouTube 和 Bilibili 的相关视频。
4. 调用 OpenAI-compatible 模型接口生成结构化 Markdown 文章。
5. 将文章保存到本地 `output/` 目录。
6. 可以通过定时任务每天自动运行。

在 DSH 中，插件会显示一个图形化设置卡片。卡片可以检查 worker、配置文件和凭据状态，也可以输入一次性 API Key 并立即生成文章。

## 2. 插件的组成

插件由三部分组成：

```text
DSH 图形界面
    ↓
Node.js 桥接层（lib/index.js）
    ↓
Python worker（src/daily_insight/）
```

- `client/client.js`：在 DSH 设置页显示图形化卡片。
- `lib/index.js`：提供健康检查和生成接口，并启动 Python worker。
- `src/daily_insight/`：负责配置、搜索、视频发现、模型调用、定时运行和文件导出。
- `harness/`：保存 DSH 的 manifest 和配置 schema。
- `cordis.patch.yml`：将插件插入 DSH 当前配置。

插件包只包含 DSH 的 JavaScript 部分。Python worker 需要在本机单独安装，并通过 `DAILY_INSIGHT_ROOT` 指向本项目目录。

## 3. 安装 Python worker

要求 Python 3.10 或更高版本。推荐在项目目录创建虚拟环境：

```powershell
cd D:\DSH_Workspace\DSH_deplugin
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -e ".[test]"
```

如果已经有项目中的 `.venv`，直接执行安装命令即可：

```powershell
.\.venv\Scripts\python.exe -m pip install -e ".[test]"
```

## 4. 安装 DSH 插件

在项目目录生成新的 npm 插件包：

```powershell
npm pack --pack-destination .\dist
```

生成的文件类似：

```text
dist\daily-insight-harness-plugin-0.1.0.tgz
```

在 DSH 的插件管理界面中安装这个 `.tgz` 文件，然后重启 DSH。

如果 DSH 使用命令行安装插件，请使用这个新生成的完整文件路径。不要继续使用修改前生成的旧 `.tgz` 文件。

## 5. 设置 DSH 运行环境

启动 DSH 之前，在同一个 PowerShell 窗口设置：

```powershell
$env:DAILY_INSIGHT_ROOT = "D:\DSH_Workspace\DSH_deplugin"
$env:PYTHON = "D:\DSH_Workspace\DSH_deplugin\.venv\Scripts\python.exe"
```

默认配置路径是：

```text
D:\DSH_Workspace\DSH_deplugin\config\default.yaml
```

如果 DSH 使用其他配置文件，可以额外设置：

```powershell
$env:DAILY_INSIGHT_CONFIG = "D:\DSH_Workspace\DSH_deplugin\config\local.yaml"
```

桥接层会把这个配置路径传给 Python worker，不会悄悄改用另一个配置文件。

## 6. 配置 API Key

有两种方式可以提供模型密钥。

### 方式一：在 DSH 界面临时输入

打开 Daily Insight 卡片，在 API Key 输入框中填写密钥，再点击“立即生成”。这个密钥只用于本次请求，不会保存到浏览器存储。

### 方式二：使用环境变量

在启动 DSH 的 PowerShell 中设置：

```powershell
$env:DEEPSEEK_API_KEY = "你的 API Key"
```

不要把真实 API Key 写进 YAML、README、GitHub 提交或聊天消息中。

如果配置使用 SerpAPI 或 Tavily，还需要设置对应密钥：

```powershell
$env:SERPAPI_KEY = "你的 SerpAPI Key"
$env:TAVILY_KEY = "你的 Tavily Key"
```

## 7. 在 DSH 中使用

重启 DSH 后，在设置页找到 `Daily Insight` 卡片：

1. 展开卡片。
2. 点击“刷新”，查看连接状态。
3. 确认 `Worker` 和 `配置` 都显示为可用。
4. 输入 API Key，或者确认 DSH 进程已经继承了环境变量。
5. 点击“立即生成”。
6. 等待按钮变成“生成中……”并完成。

成功后，界面会显示 worker 的运行输出，文章会保存到配置中的输出目录。

默认输出目录是：

```text
D:\DSH_Workspace\DSH_deplugin\output
```

默认文件名格式是：

```text
{date}_{topic_slug}.md
```

例如主题为 `AI Agent` 时，文件名可能是：

```text
2026-09-12_ai-agent.md
```

如果文件已经存在，插件会自动生成 `_2`、`_3` 等后缀，不会覆盖原文章。

## 8. 配置文件说明

配置文件位于 `config/default.yaml`，主要字段如下：

```yaml
schedule:
  time: "08:00"
  timezone: "Asia/Shanghai"
topics:
  - "AI Agent"
  - "大模型"
  - "开源硬件"
search:
  engine: "duckduckgo"
  max_results_per_keyword: 5
  max_keywords: 3
video:
  platforms: ["youtube", "bilibili"]
  max_videos: 3
llm:
  provider: "deepseek"
  base_url: "https://api.deepseek.com/v1"
  model: "deepseek-chat"
  temperature: 0.7
  max_tokens: 4096
output:
  dir: "./output"
  naming: "{date}_{topic_slug}.md"
```

`llm.base_url` 支持 HTTPS 的 OpenAI-compatible 接口。如果使用其他模型服务，只需要修改接口地址和模型名，API Key 仍然通过环境变量或界面输入提供。

## 9. 命令行运行

不使用 DSH 图形界面时，也可以直接运行 Python worker：

```powershell
.\.venv\Scripts\python.exe -m daily_insight.main run --config config\default.yaml
```

启动每日定时任务：

```powershell
.\.venv\Scripts\python.exe -m daily_insight.main daemon --config config\default.yaml
```

启动成功后会打印下一次执行时间。使用 `Ctrl+C` 可以停止守护进程。

## 10. 验证安装是否成功

先执行不调用真实模型的离线测试：

```powershell
$env:PYTHONDONTWRITEBYTECODE = "1"
.\.venv\Scripts\python.exe -B -m pytest -q -p no:cacheprovider
```

JavaScript 语法检查：

```powershell
node --check lib/index.js
node --check client/client.js
```

如果 DSH 卡片显示“服务可用”，说明 DSH 已经能找到 worker 和配置文件。再点击“立即生成”才会真正调用搜索服务和模型接口。

## 11. 常见问题

### 看不到 Daily Insight 卡片

确认安装的是最新生成的 `.tgz`，然后完全重启 DSH。旧插件包不会自动包含最新修改。

### 显示 Worker 不可用

检查 `DAILY_INSIGHT_ROOT` 是否指向包含以下文件的目录：

```text
src\daily_insight\main.py
config\default.yaml
```

### 显示配置文件缺失

检查 `DAILY_INSIGHT_CONFIG`，或者确认 worker 目录下存在 `config\default.yaml`。

### 提示缺少 API Key

在 DSH 卡片中临时输入密钥，或者在启动 DSH 前设置 `DEEPSEEK_API_KEY`。

### 生成失败或返回空文章

检查网络、搜索引擎密钥、模型接口地址和模型名称。搜索结果和模型生成内容属于外部数据，发布前应人工检查来源和引用。
